## Goal

Ship a bin-ready TypeScript CLI that turns a **pnpm + turbo** monorepo into a **self-contained subway HTML**: packages as stations, workspace deps as rails, **synthetic/replayable** turbo-task trains. README **GIF required** (manual OK) + `fixtures/mini-mono`.

Slogan: Your monorepo as a subway — trains run when turbo does.  
Honesty: v0.1 trains are **synthetic/replay** (not live turbo attach). Document in README.

## Architecture

```
CLI (bin/turbometro)
  ├─ findRoot(cwd)            → find-up pnpm-workspace.yaml
  ├─ parseWorkspace(root)     → Graph { nodes, edges }  // workspace:* only as rails
  ├─ parseTurbo(root)         → tasks legend             // turbo.json | turbo.jsonc
  ├─ normalizeCycles(graph)   → warn + drop cycle edges (D15)
  ├─ scaleGuard(nPackages)    → warn≥40, fail≥150 (--force)
  ├─ toDagMapInput(graph)     → routes/classes mapping (explicit rules in layout.ts)
  ├─ layoutMetro(...)         → positions + path `d`     // vendor/23min DAG-map
  ├─ buildReplay(...)         → --replay | --demo | **default synthetic**
  └─ renderHtml(...)          → ./metro.html (single self-contained file)
```

### Workspace → dag-map mapping (D16)

- Each workspace package → one station node
- Each workspace dep edge → rail segment
- Route/class: prefer package directory prefix (`apps` / `packages`) or turbo task color only on trains (not duplicate rail layers)
- Document chosen heuristic in `layout.ts` header ASCII comment; adjust if vendor API requires `route` ids

### Mental model

| Metro | Data |
|-------|------|
| Station | Workspace package |
| Rail | Workspace dependency edge |
| Train color / event | Turbo task name + status |
| Motion | Short dep path → station; else **station pulse** (D14) |

### Data flow

```
cwd ──find-up──► root
 │
 ├─ missing pnpm-workspace / turbo.json(c) / empty / n≥150 → stderr + exit 1
 ├─ cycles → warn, drop edges, continue
 │
 ├─ Graph ──► mapping ──► vendor layoutMetro ──► SVG
 │
 └─ default synthetic | --demo | --replay
        │
        └─ CSS offset-path / pulse inlined in HTML
```

## Failure modes

| Failure | Behavior |
|---------|----------|
| No pnpm-workspace (find-up miss) | exit 1 |
| No turbo.json / turbo.jsonc | exit 1 |
| Legacy `pipeline` key only | best-effort map to tasks; else exit 1 with hint |
| Dependency cycle | warn; drop cycle edges; continue |
| ≥150 packages | exit 1 unless `--force` |
| 40–149 packages | warn; continue |
| Empty workspace | exit 1 |
